# Summary

## Context

- Describe the meeting or note context using only information present in the source note.

## Key points

- List the most important points in concise bullets.

## Decisions

- Capture confirmed decisions only.
- If there are no explicit decisions, say so.

## Action items

- List action items with owners only when they are clearly stated.
- If ownership is unclear, mention the uncertainty explicitly.

## Risks or uncertainties

- Mention missing information, ambiguity, open questions, and unclear next steps.
